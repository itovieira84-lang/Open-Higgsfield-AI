# Daana Alimentos — guia da marca

Pasta de referência do cliente para criação de conteúdos (vídeos, motions e artes de produtos).

## Logo

| Arquivo | Uso |
| --- | --- |
| `logo/daana-alimentos-logo.webp` | Arquivo original enviado pelo cliente (2000×758, fundo transparente) |
| `logo/daana-alimentos-logo.png` | Mesma imagem em PNG, para ferramentas que não aceitam WebP |

Descrição: selo hexagonal vermelho com o nome **DAANA** em letras brancas. O segundo "A" é cursivo, maior, e atravessa o selo de cima a baixo. Abaixo, à direita, aparece **ALIMENTOS** em branco. Três faixas horizontais vermelhas saem de cada lado do selo.

Cores:

- Vermelho: `#E5011C` (aprox., amostrado do arquivo)
- Branco: `#FFFFFF`

## Regras obrigatórias para qualquer conteúdo

1. **Realismo sempre.** Imagens e vídeos devem parecer fotografia/filmagem real, nunca ilustração ou "cara de IA".
2. **Nunca desconfigurar a logomarca.** Não redesenhar, distorcer, recolorir, trocar fonte, cortar nem gerar a logo por IA; usar sempre o arquivo original sobreposto.
3. **Produtos e embalagens fiéis.** Rótulos, textos, cores e formatos das embalagens devem ficar idênticos aos reais; usar fotos reais dos produtos como referência (image-to-image / image-to-video) em vez de gerar do zero.
